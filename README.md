# 铁路信号联锁测试用例编排与回归记录平台

源提示词编号：14。包含道岔、信号机、轨道区段与进路关系，Canvas 站场缩放与定位，受设备变化影响的回归范围推导，用例步骤/预期/依赖编排，实时执行同步、断线重试、失败证据、基线锁定和测试报告导出。

## 换班防覆盖的可恢复闭环

步骤签出、执行证据与发布计票通过 `src/domain` 下的两层服务接成闭环：

- **唯一签出**（`domain/server.ts`）：同一执行员同一时刻只持有一个有效签出，同一用例只允许一个持有者；非持有者和版本过期签出一律只读。
- **交班草稿**：换人（`shift-handover`）后原执行员的未提交步骤整体进入交班草稿，原签出立即让出；新人“接续重开”会拿到新签出号，草稿步骤保留“待提交”标记，不会自动计票。
- **证据只增不改**：提交步骤时封存证据（含签出号、请求号、用例版本指纹、操作者）；晚到/重放结果只留档不覆盖。每步按用例版本指纹采信最新有效证据。
- **版本失效最小化**：设备或进路版本变化只把**关联进路上的步骤**标记失效，在办签出转只读、未提交内容留只读草稿；已封存证据一律保留。确认修订（`confirm-revision`）后按有效证据重算门禁，指纹不符的旧证据留档但不采信。
- **请求号幂等恢复**（`domain/transport.ts`）：每个写命令带全局唯一请求号；发出前断网进入发件箱（服务端未执行），应答丢失则服务端已写入、恢复时凭请求号重放，账本去重，**重放不重复封存证据、不重复计票**。
- **旧记录补齐来源**：引导时为缺少签出号的历史执行记录按执行历史补登 `CO-LEGACY-*` 来源签出号与“历史补齐”证据指纹，门禁据此重算。

页面落点：执行页显示当前持有者、交班草稿、发件箱与证据链；发布页可模拟设备/进路/全站版本变化、确认修订、查看重算结果与写入账本，并可按请求号一键重放。

状态持久化在 `localStorage`（键 `yy57-interlocking-server-v2`），通过 `BroadcastChannel` 跨标签页同步，可直接开两个浏览器标签复现“两页面同时操作”。发布页「重置演示数据」可恢复初始场景。

## 技术栈

Vue 3、Naive UI、Pinia、Vue Router、TanStack Query、Axios、WebSocket 模拟、Canvas、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

开发地址：http://localhost:62057

```bash
npm run build     # 类型检查 + 构建
npm run verify    # 领域闭环端到端验证（70 项断言：唯一签出/交班/失效/重算/幂等恢复）
```
